# Docs definitivos

Aquí se guardan los documentos que MISPORT ha revisado y aprobado como versión definitiva (no borradores de trabajo).

## Convención

- Un archivo Markdown (`.md`) por documento.
- Nombre: `AAAA-MM-DD-titulo-breve.md` (fecha de aprobación + título corto), por ejemplo:
  `2026-07-09-modelo-economico.md`
- Si un documento aprobado se revisa más adelante, se actualiza el mismo archivo (el historial de git ya guarda las versiones anteriores) en vez de crear copias con sufijos como "v2" o "final-final".
